# EPV benchmark release candidate

`manifest.json` is the external entry point: 14 representative cases spanning positive verification, negative counterexamples, V3 certificates, synthesis SAT/UNSAT, repair, malformed inputs, certificate attacks, and differential validation. Historical complete registries remain in `m5/`, `m6/`, and `m7/` with machine-readable results and scaling data.

The release manifest intentionally references the audited historical corpora instead of copying proof or result bytes. Reproduction commands are relative to the repository root.
