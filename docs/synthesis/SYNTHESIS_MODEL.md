# Synthesis model

`epv-synthesis-problem-v1` declares the auction domain, finite values, winner-payment domain, allocation family, loser-payment normalization, immutable property versions, optional objective, and exact prior. Canonical JSON supplies the problem hash.

`epv-synthesis-result-v1` distinguishes candidate, exhaustive optimum, bounded-class UNSAT, timeout, unknown, and error. Candidates are decoded into normal EIR mechanisms and rechecked by the authoritative property evaluators. Solver assignments alone are never accepted.
