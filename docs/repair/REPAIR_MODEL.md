# Repair model

M6 payment-only repair preserves the efficient allocation table and searches bounded winner payments. Every repaired mechanism is decoded and independently reverified against all hard requirements.

The first-price `{0,1}` benchmark has an exact repair changing one payment cell by one unit. The repaired table is DSIC, IR, WBB, feasible, and efficient but is not claimed to be uniquely or generally Vickrey.
