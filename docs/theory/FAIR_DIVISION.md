# Fair division

EPV's fair-division fragment assigns finite indivisible goods completely among a finite agent set. Each agent has an explicit additive, nonnegative integer valuation. The reference example uses two agents and three goods.

Feasibility assigns every known good exactly once. Envy-freeness compares bundles using the envier's valuation. EF1 requires that any envy can be eliminated by removing at most one good from the envied bundle. Pareto efficiency enumerates feasible alternative allocations and rejects one that weakly improves every agent and strictly improves at least one.

The framework does not support divisible goods, non-additive or negative valuations, random allocations, EFX, market equilibria, or scale beyond the measured small instances.
