# EPL Examples

Executable examples are in `examples/`. `second_price.epl` and `first_price.epl` differ only in the payment rule. `winner_pays_own_bid.epl` documents a mislabeled/malformed second-price mechanism. `subsidized_mechanism.epl`, `double_allocation.epl`, and `always_agent_zero.epl` are negative benchmarks.

Formatting changes alter the source hash but not the semantic mechanism hash. Requested properties are intentionally excluded from mechanism identity.
