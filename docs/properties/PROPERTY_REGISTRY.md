# Property registry

M5 introduces eight immutable domain-specific IDs:

- `epv.matching.feasibility.v1`
- `epv.matching.individual_rationality.v1`
- `epv.matching.stability.v1`
- `epv.matching.strategyproof_proposer.v1`
- `epv.fair_division.feasibility.v1`
- `epv.fair_division.envy_free.v1`
- `epv.fair_division.ef1.v1`
- `epv.fair_division.pareto_efficiency.v1`

Each registry entry states its domain, formal definition, required semantic features, quantifiers, negated witness, assumptions, and supported assurance levels. Historical auction property IDs are unchanged.
