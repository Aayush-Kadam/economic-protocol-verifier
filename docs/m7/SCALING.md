# Scaling

Measured DSIC obligations ranged from 16 cases (2 bidders, 2 values) to 128 cases (4 bidders, 2 values). Compilation remained below 16 ms and both solvers below 30 ms in this sample.

Synthesis grew from 1 candidate/3.9 ms to 16/13.4 ms and 81/52.2 ms. The theoretical table space is exponential in report profiles, so the practical synthesis envelope remains tiny. No claim is made beyond four bidders for verification or 81 measured synthesis candidates.
