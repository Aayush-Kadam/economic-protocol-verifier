# Economic Protocol Verifier (EPV)

EPV is a research program for auditable verification of precisely specified economic mechanisms. It is not yet a verifier. Milestone M0 establishes the scientific scope, prior-art boundary, trust model, and falsification criteria before implementation.

Core rule: sampled evidence is never reported as mathematical verification. Every future result must state its domain, assumptions, arithmetic, backend, and assurance level.
