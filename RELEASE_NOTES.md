# EPV 0.1.0 research release candidate

EPV 0.1.0 is a local, unpublished research preview for external human review. It demonstrates bounded verification across auctions, matching, and fair division; replayable exact-minimum counterexamples; selected independently checked Alethe bundles; and tiny finite auction synthesis/repair.

The release adds a coherent CLI, a 14-property registry, consolidated benchmark manifest, representative/full reproduction command, locked tool manifest, canonical trust statement, external quickstart, hostile-referee audit, and full manuscript.

The release does not claim universal proofs, a verified compiler, scalable synthesis, voting, Bayesian/randomized mechanisms, or publication readiness. V3 requires pinned Carcara through the validated WSL setup. The release remains local and has not been published, submitted, or made public.
