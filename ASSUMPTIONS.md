# Assumptions Register

Initial assumptions are explicit declarations, not inferred defaults:

- deterministic direct revelation;
- private values;
- quasi-linear utility;
- exact rational money and value arithmetic;
- payment positive means agent pays mechanism;
- declared outside option, default prohibited unless explicitly specified;
- deterministic explicit tie-breaking;
- finite and nonempty spaces;
- total allocation/payment functions.

An omitted relevant assumption is a semantic error, not a reason to guess.
